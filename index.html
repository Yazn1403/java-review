أساسيات البرمجة ولغة جافا (Programs & Java Intro)

ما هو البرنامج؟ (Program)

مجموعة من التعليمات الموجهة للحاسب لأداء مهام محددة[cite: 153]. يشبه الوصفة الطبية (يحتوي على متغيرات كالمكونات، وتعليمات كالخطوات)[cite: 153]. الحاسب بدونا برنامج عبارة عن آلة فارغة[cite: 153].

المترجمات والمفسرين (Compilers & Interpreters)

  • الـ Compiler (javac): يترجم البرنامج بالكامل مرة واحدة إلى Bytecode (ملف .class) قبل التنفيذ[cite: 161].
  • الـ Interpreter (JVM): يقرأ وينفذ الـ Bytecode تعليمة تلو الأخرى[cite: 162].
  • JIT (Just-In-Time): يترجم الـ Bytecode أثناء التشغيل ليعطي سرعة قريبة من لغة الآلة[cite: 176].

مكونات بيئة جافا الكبرى (JDK, JRE, JVM):

JVM: بيئة التشغيل الافتراضية لتنفيذ الـ Bytecode[cite: 179].
JRE: يتكون من (JVM + المكتبات الأساسية)[cite: 179].
JDK: يتكون من (JRE + أدوات المطور والمترجم Compiler)[cite: 180].

الخوارزميات وهيكل برنامج جافا والأخطاء

رموز مخططات التدفق (Flowchart Symbols)

  • 🟢 Oval (بيضاوي): بداية أو نهاية البرنامج[cite: 107].
  • parallelogram Parallelogram (متوازي أضلاع): عمليات الإدخال والإخراج[cite: 107].
  • rectangle Rectangle (مستطيل): العمليات الحسابية والمعالجة[cite: 107].
  • diamond Diamond (معين): القرارات والشرط (IF/ELSE)[cite: 107].

أنواع الأخطاء البرمجية (Bugs & Errors)

  • Syntax Errors: أخطاء قواعدية يكتشفها المترجم مثل نسيان (;)[cite: 122].
  • Runtime Errors: أخطاء تظهر أثناء التشغيل وتوقف البرنامج مثل القسمة على صفر (1/0)[cite: 123].
  • Logic Errors: أخطاء منطقية لا توقف البرنامج ولكن تعطي نتائج خاطئة (الأصعب)[cite: 124].

الهيكل الأساسي لبرنامج جافا (5 مكونات رئيسية):

// 1. تعليقات توثيقية (Documentation Comments)
package packageName; // 2. اسم الحزمة (اختياري)
import java.util.Scanner; // 3. استيراد المكتبات

public class ClassName { // 4. تعريف الكلاس
    public static void main(String[] args) { // 5. الدالة الرئيسية
        // الجمل والتعليمات البرمجية (Statements)
    }
}

الثوابت (Constants)

تُعرف باستخدام الكلمة المفتاحية final وتُكتب أحرفها بالكامل بأبجدية كبيرة يفصل بينها شرطة سفلية[cite: 38, 39]: 

public static final double PI = 3.14159;

قواعد المعرفات (Identifiers Rules)

تبدأ بحرف أو (_) أو ($)، ولا يجوز أن تبدأ برقم[cite: 84]. لغة جافا حساسة لحالة الأحرف (Case-sensitive)[cite: 85].

محاضرة 4

العمليات الحسابية والمنطقية والتحويل (Type Casting)

توافق التعيين (Assignment Compatibility)

يمكنك تخزين قيمة من نوع أصغر في نوع أكبر يقع إلى اليمين في التسلسل:
byte → short → int → long → float → double[cite: 34]

التحويل القسري (Type Casting)

لتغيير النوع قسرياً مع حذف الكسور (Truncation)[cite: 35]:
double d = 9.99; int x = (int)d; // x = 9

العمليات المنطقية (Logical Operators)

&& (AND): صحيح إذا كلاهما صحيح[cite: 47].
|| (OR): صحيح إذا أحدهما صحيح[cite: 47].
! (NOT): يعكس القيمة[cite: 47].

أولويات العمليات الحسابية (Precedence): 1. الأقواس ()  |  2. الضرب والقسمة وباقي القسمة * / %  |  3. الجمع والطرح + -  |  4. التعيين =[cite: 53]

الإدخال والإخراج المتقدم (Scanner & Printf)

كلاس الإدخال Scanner

import java.util.Scanner;

Scanner keyboard = new Scanner(System.in);
int n = keyboard.nextInt();
double d = keyboard.nextDouble();
String s = keyboard.next();

⚠️ فخ دالة nextLine():

عند قراءة رقم ثم محاولة قراءة نص بـ nextLine()، يبقى حرف السطر الجديد (\n) في الذاكرة المؤقتة[cite: 10].

الحل:

int n = keyboard.nextInt();
keyboard.nextLine(); // امتصاص السطر الفارغ
String s = keyboard.nextLine();

التنسيق الاحترافي printf():

double price = 19.57;
System.out.printf("Price: %6.1f", price); // الناتج:   19.6

محددات التنسيق: %d للأعداد الصحيحة، %f للأعداد العشرية، %s للنصوص[cite: 21].
