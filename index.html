1 المحاضرة الأولى: البرامج، لغات البرمجة وتاريخ جافا

L01_Intro

💻 ما هو البرنامج؟ (What is a Program?)

البرنامج هو **مجموعة من التعليمات** للكمبيوتر تنظم طريقة أداء المهام واستخراج النتائج[cite: 153]. يشبه البرنامج **وصفة الطهي (Recipe)**[cite: 153]:

  • المكونات (Ingredients): تمثل المتغيرات (Variables)[cite: 153].
  • الخطوات (Directions): تمثل التعليمات والجمل البرمجية (Statements)[cite: 153].

⚙️ مستويات لغات البرمجة (Programming Levels)

  • Low-Level Languages: قريبة جداً من الآلة مثل لغة التجميع (Assembly) ولغة الآلة (Machine Language: 0s & 1s)[cite: 155, 157].
  • High-Level Languages: قريبة من فهم الإنسان مثل Java, C++, Python[cite: 157, 158]. يجب ترجمتها إلى لغة الآلة لتُنفذ[cite: 158].

الفرق بين المترجم (Compiler) والمفسر (Interpreter)

وجه المقارنة المترجم (Compiler - javac) المفسر (Interpreter - JVM)
آلية العمل يطبق الترجمة على **كامل الكود مرة واحدة** قبل التنفيذ[cite: 161]. يترجم وينفذ الكود **سطراً بسطر** بشكل متسلسل[cite: 162].
الناتج في جافا يحول السورس كود (.java) إلى بايتركود (.class)[cite: 161]. يحول الـ Bytecode إلى تعليمات لغة آلة يفهمها للمعالج[cite: 162].

بيئة تطوير جافا: العلاقة بين JDK, JRE, JVM

1. JVM (Java Virtual Machine)

الآلة الافتراضية التي تقوم بتفسير وتنفيذ الـ Bytecode[cite: 162]. تضمن ميزة Write Once, Run Anywhere[cite: 166].

2. JRE (Java Runtime Environment)

يتكون من: JVM + مكتبات الكلاسات (Class Libraries)[cite: 179]. يلزم لتشغيل البرامج[cite: 179].

3. JDK (Java Development Kit)

يتكون من: JRE + أدوات التطوير والمترجم (javac)[cite: 180]. يلزم لكتابة وتطوير الكود[cite: 180].

أنواع الأخطاء البرمجية الثلاثة (Programming Errors)

1. Syntax Errors

أخطاء القواعد واللغة. يكتشفها الـ Compiler ويمنع ترجمة الملف[cite: 122].

مثال: نسيان الفاصلة المنقوطة (;)[cite: 122].

2. Runtime Errors

أخطاء تحدث أثناء تشغيل البرنامج وتتسبب في إيقافه المفاجئ[cite: 123].

مثال: القسمة على صفر (1 / 0)[cite: 123].

3. Logic Errors

يعمل البرنامج دون توقف ولكن يعطي نتائج خطأ. الأصعب في الاكتشاف[cite: 124].

مثال: كتابة قانون حسابي خاطئ[cite: 124].

قواعد المعرفات (Identifiers Rules)

  • تتكون فقط من: أصل الحروف، أرقام، شرطة سفلية (_)، أو علامة ($)[cite: 84].
  • ممنوع: أن يبدأ المعرف برقم (مثال: 7eleven خطأ)[cite: 84].
  • ممنوع: استخدام الكلمات المحجوزة مثل (class, int, public)[cite: 86].
  • جافا حساسة للحالة (Case-Sensitive): count و Count معرفان مختلفان[cite: 85].

تعريف الثوابت (Named Constants)

تُعرف القيم الثابتة باستخدام الكلمة المحجوزة final وتسميتها بجميع الأحرف الكبيرة تفصل بينها شرطة سفلية[cite: 38, 39]: 

public static final double PI = 3.14159;
public static final int DAYS_IN_WEEK = 7;

4 المحاضرة الرابعة: العمليات الحسابية، التحويل والأولويات

L04_Expressions

ترتيب أولويات العمليات (Precedence Rules)

  1. الأقواس Parentheses: ( ) تُنفذ أولاً من الداخل للخارج[cite: 52, 53].
  2. الضرب والقسمة وباقي القسمة: * / % من اليسار لليمين[cite: 53].
  3. الجمع والطرح: + - من اليسار لليمين[cite: 53].
  4. معامل التعيين: = يُنفذ أخيراً[cite: 53].

التوافق والتحويل القسري (Type Casting)

التحويل التلقائي يتم من اليسار لليمين: byte → short → int → long → float → double[cite: 34]

التحويل العكسي يتطلب (Casting) ويحذف الكسر (Truncation)[cite: 35]: 

double distance = 9.89;
int points = (int)distance; // points = 9

معاملات الزيادة والنقصان القبلي والبعدي (Prefix vs Postfix)

// Prefix (++m)

يزيد القيمة أولاً ثم يحسب التعبير[cite: 60]:

int m = 4; int res = 3 * (++m);
// m=5, res=15[cite: 60]

// Postfix (m++)

يحسب التعبير بالقيمة الحالية ثم يزيد[cite: 60]:

int m = 4; int res = 3 * (m++);
// m=5, res=12[cite: 60]
