1. مقدمة الخوارزميات ولغة جافا (Algorithms & Java Intro)

ما هي الخوارزمية (Algorithm)؟

مجموعة من الخطوات المحدودة والمتسلسلة والواضحة لحل مشكلة معينة[cite: 106]. يتم تمثيلها إما بـ **Flowcharts** (مخططات تدفق رسومية) أو **Pseudocode** (شفرة وصفية بشرية)[cite: 106].

أنواع الأخطاء البرمجية (Programming Errors)

  • Syntax Errors: أخطاء نحوية وقواعدية يكتشفها المترجم (Compiler) مثل نسيان (;)[cite: 122].
  • Runtime Errors: أخطاء تظهر أثناء تشغيل البرنامج وتوقفه مفاجئاً مثل القسمة على صفر (0/)[cite: 123].
  • Logic Errors: أخطاء في منطق البرنامج تجعله يعمل بدون توقف ولكن يعطي نتائج خاطئة (الأصعب اكتشافاً)[cite: 124].

بيئة جافا والمكونات (JDK, JRE, JVM):

المكون الوظيفة الأساسية
JVM (Java Virtual Machine) يترجم وينفذ الـ Bytecode إلى لغة الآلة الخاصة بالجهاز[cite: 162].
JRE (Java Runtime Environment) يتكون من (JVM + المكتبات الأساسية) لتشغيل برامج جافا[cite: 179].
JDK (Java Development Kit) يتكون من (JRE + أدوات المطور مثل المترجم Compiler) لكتابة وتطوير وبرمجة الجافا[cite: 180].

2. المتغيرات وأنواع البيانات (Variables & Data Types)

أنواع البيانات البدائية (Primitive Types):

  • الأعداد الصحيحة: byte, short, int (الأكثر استخداماً), long[cite: 80].
  • الأعداد العشرية: float, double (الأكثر دقة)[cite: 80].
  • الرموز: char (لحرف واحد، يدعم Unicode)[cite: 80].
  • المنطقية: boolean (تحمل قيمة true أو false)[cite: 80].

أنواع البيانات غير البدائية (Non-Primitive):

مثل String (النصوص)، المصفوفات (Arrays)، والكلاسات المعرفة من قبل المستخدم[cite: 78]. تبدأ بحرف كبير (Uppercase) وتمتلك دوال جاهزة مثل length()[cite: 79, 82].

قواعد تسمية المعرفات (Identifiers):

تبدأ بحرف، أو علامة سفلية (_)، أو علامة ($)، ولا يجوز أن تبدأ برقم[cite: 84]. لغة جافا حساسة لحالة الأسطر (Case-sensitive)[cite: 85]. الأسماء الثابتة (Constants) تُكتب بأحرف كبيره بينها شرطة سفلية مثل DAYS_PER_WEEK وتعريفها كالتالي: public static final double PI = 3.14159;[cite: 38, 39].

3. العمليات الحسابية والتعابير (Arithmetic & Expressions)

العمليات الحسابية

الجمع (+) والطرح (-) والضرب (*) والقسمة (/) وباقي القسمة (%)[cite: 46]. القسمة الصحيحة 99 / 100 تساوي 0 لأنها تحذف الكسور[cite: 48].

الزيادة والنقصان

معاملات الزيادة والنقصان القبلي والبعدي (++count أو count++) لزيادة أو نقص القيمة بمقدار 1[cite: 58].

الأولويات (Precedence)

الأقواس أولاً، ثم الضرب والقسمة وباقي القسمة من اليسار لليمين، ثم الجمع والطرح[cite: 53].

التخزين المؤقت والتحويل (Type Casting):

يمكن تحويل نوع البيانات مؤقتاً عبر وضع النوع بين قوسين مثل:

double distance = 9.0;
int points = (int)distance; // القيمة تصبح 9 ويتم قطع الكسر

4. الإخراج والإدخال الأساسي (Basic Input/Output & Scanner)

استخدام كلاس Scanner للإدخال:

import java.util.Scanner; // 1. الاستيراد

Scanner keyboard = new Scanner(System.in); // 2. التهيئة
int age = keyboard.nextInt(); // قراءة عدد صحيح
String name = keyboard.next(); // قراءة كلمة

من الدوال الشهيرة: next()، nextLine()، nextDouble()[cite: 4].

⚠️ تنبيه هامة جداً لـ nextLine():

عند قراءة رقم (مثل nextInt()) ثم متبوعاً بنص (مثل nextLine())، يبقى رمز الانتقال للسطر التالي (\n) في الذاكرة المؤقتة، مما يتسبب في قراءة نص فارغ ""[cite: 9, 10].

الحل:

int n = keyboard.nextInt();
keyboard.nextLine(); // امتصاص السطر الفارغ
String text = keyboard.nextLine();

التنسيق المتقدم باستخدام printf:

يتيح التحكم في عدد المنازل العشرية ومحاذاة النصوص والأرقام:

double price = 19.57;
System.out.printf("Price: %6.1f", price); // الناتج:   19.6 (بعرض 6 خانات ومنزلة عشرية واحدة)
  • %d للأعداد الصحيحة، %f للأعداد العشرية، %s للنصوص[cite: 21].
  • العلامات: + لإظهار الإشارة، - للمحاذاة لليسار، 0 للتعبئة بالأصفار[cite: 23].
